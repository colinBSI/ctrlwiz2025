## Input Layer

| Option | Description | Selected |
|--------|-------------|----------|
| ViGEm Bus Driver | User installs free open-source ViGEm Bus Driver; Stadia re-exposed as XInput; zero code changes to GamePad.GetState(). Requires driver install. | ✓ |
| SharpDX.DirectInput | NuGet package reads HID devices directly; no user driver install; adds dependency and device enumeration logic. | |
| Windows.Gaming.Input | WinRT API via COM from .NET 4.8; messy interop, limited examples. | |

**User's choice:** ViGEm Bus Driver
**Notes:** Minimal code change, leverages existing XInput path entirely.

### Follow-up: Missing ViGEm

| Option | Description | Selected |

## Button Naming in UI

| Option | Description | Selected |
|--------|-------------|----------|
| Xbox labels always | Keep A/B/X/Y/LB/RB/LT/RT everywhere; no detection code needed. | ✓ |
| Auto-detect and swap labels | Detect Stadia VID/PID; swap labels to L1/R1/L2/R2 etc. Adds complexity. | |
| User-selectable controller type | Dropdown in Settings: Xbox / Stadia. Requires UI addition. | |

**User's choice:** Xbox labels always
**Notes:** Since ViGEm maps Stadia 1:1 to Xbox button indices, Xbox labels are accurate.

## Multi-Controller Coexistence

| Option | Description | Selected |
|--------|-------------|----------|
| First connected wins | Uses XInput player index 0; no UI change. | ✓ |
| User picks in Settings | Add 'Controller slot' setting (1–4). | |
| Any active controller | Poll all 4 XInput slots; use whichever sends non-zero input. | |

**User's choice:** First connected wins
**Notes:** Simple; user manages slot assignment at OS/driver level if needed.
