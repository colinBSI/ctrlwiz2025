**Scenario A — With Stadia controller connected via USB:**

1. Plug the Google Stadia controller in via USB-C.
2. Request Admin elevation (Admin By Request if needed) to ensure NW can write user settings.
3. Launch Navisworks 2025.
4. Click the CtrlWiz ribbon button to activate the plugin.
5. **Expected:** A dialog appears titled "Stadia Controller Detected" with the message about ViGEm Bus Driver and Yes/No buttons.
6. Click **No** (to avoid opening the browser — just confirm the dialog appeared).
7. Activate the plugin a second time (click the CtrlWiz button again).
8. **Expected:** No dialog appears on the second activation (one-time suppression working).

**Scenario B — Without Stadia controller connected:**

1. Unplug the Stadia controller (or use a machine where it is not connected).
2. Launch Navisworks 2025.
3. Click the CtrlWiz ribbon button.
4. **Expected:** No dialog appears. Plugin activates normally.

**Scenario C — Reset and test "Yes" branch (optional, if Scenario A worked):**

1. Delete the user settings file to reset `StadiaViGEmDialogShown` to False.
   The user settings file is at: `%LOCALAPPDATA%\CtrlWiz_NW_UI\` (or similar ApplicationData path).
   Alternatively: use Registry Editor to find `HKCU\Software\CtrlWiz\CtrlWiz.NW.UI.Properties.Settings` and delete the `StadiaViGEmDialogShown` value.
2. Activate the plugin again with Stadia connected.
3. Click **Yes** this time.
4. **Expected:** Default browser opens to `https://github.com/nefarius/ViGEmBus/releases`.

**If Stadia controller is not available for testing:**
- Verify Scenario B (no dialog without Stadia) is sufficient for this session.
