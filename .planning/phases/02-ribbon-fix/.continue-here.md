# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through actual failure.

- [ ] CONSTRAINT: PROCESS-MODULES-MISLEADING — `Get-Process.Modules` does NOT show byte-array loaded managed assemblies. NW loads plugins via `Assembly.Load(byte[])`, so CtrlWizNW.dll and iConstruct DLLs both appear absent from Process.Modules even when loaded. Empty Module check ≠ DLL not loading.

- [ ] CONSTRAINT: PDFSDK-TRANSITIVE-DEPS — PaddleSDK.dll requires StructureMap, Newtonsoft.Json, and Interop.SHDocVw. These were NOT in the Nw25 bundle and have now been manually deployed. Their presence has NOT yet fixed the load failure — there may be further transitive deps or a different root cause.

- [ ] CONSTRAINT: MSI-UNINSTALLED — The CtrlWiz MSI has been uninstalled. The bundle at `C:\ProgramData\Autodesk\ApplicationPlugins\CtrlWiz.NW.bundle\` is now fully writable (no MSI ACLs). All future deploys can be done without admin elevation.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| PROCESS-MODULES-MISLEADING | `$nw.Modules` returns empty for all managed NW plugins (iConstruct too) because NW uses byte-array loading. Empty result ≠ DLL not loaded. | blocking | Use AppDomain assembly enumeration, Fusion logging, or functional ribbon check — never Process.Modules — to diagnose managed plugin load. |
| WRONG-SERIES-CODE | PackageContents.xml series codes are NW internal API version numbers, NOT product years. NW2025=Nw22, NW2022=Nw19. Already fixed. | advisory | Verified: source and deployed PackageContents.xml both have Nw19/Nw22. |
| STATIC-CTOR-NOT-EARLY-ENOUGH | Static constructor in CmdViewpoint.cs only fires on first command execution (instantiation), not on plugin load. Cannot use it to diagnose whether DLL loaded at startup. | advisory | For load-time diagnostics, use Fusion logging or AppDomain.AssemblyLoad event. |
