  <action>
Run ALL commands below in an elevated PowerShell session (Admin By Request elevation from Task 2 must be active).

STEP A — Enable CLR Fusion logging:
```powershell
reg add "HKLM\SOFTWARE\Microsoft\.NETFramework" /v EnableLog /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\.NETFramework" /v LogPath /t REG_SZ /d "C:\FusionLogs" /f
reg add "HKLM\SOFTWARE\Microsoft\.NETFramework" /v ForceLog /t REG_DWORD /d 1 /f
reg add "HKLM\SOFTWARE\Microsoft\.NETFramework" /v LogFailures /t REG_DWORD /d 1 /f
New-Item -ItemType Directory -Force -Path 'C:\FusionLogs' | Out-Null
Write-Host "Fusion logging enabled. Log path: C:\FusionLogs"
```

STEP B — Verify registry keys were written:
```powershell
reg query "HKLM\SOFTWARE\Microsoft\.NETFramework" /v EnableLog
reg query "HKLM\SOFTWARE\Microsoft\.NETFramework" /v LogPath
reg query "HKLM\SOFTWARE\Microsoft\.NETFramework" /v ForceLog
```

STEP C — Launch NW2025 and wait for it to fully start:
Launch NW2025 manually: Start Menu → Navisworks Manage 2025 (or run `C:\Program Files\Autodesk\Navisworks Manage 2025\roamer.exe`).
Wait for NW2025 to fully load (the ribbon and workspace must be visible — approximately 30-60 seconds).
Observe: Does a CtrlWiz tab appear in the ribbon? Note: yes/no.
Close NW2025 completely (File → Exit or close the window).

STEP D — Check CtrlWizNW.log:
```powershell
$logPath = Join-Path $env:TEMP 'CtrlWizNW.log'
if (Test-Path $logPath) {
    Write-Host "=== CtrlWizNW.log EXISTS ==="
    Get-Content $logPath
} else {
    Write-Host "CtrlWizNW.log NOT CREATED — DLL did not load or Logger never initialized"
}
```

STEP E — Check NW journal:
```powershell
$localAppData = [System.Environment]::GetFolderPath('LocalApplicationData')
$journalDir = Join-Path $localAppData 'Autodesk\Navisworks Manage 2025\Journals'
if (Test-Path $journalDir) {
    Write-Host "=== Journal directory exists: $journalDir ==="
    $latest = Get-ChildItem $journalDir -Filter '*.nwjsf' | Sort-Object LastWriteTime -Descending | Select-Object -First 1
    if ($latest) {
        Write-Host "Latest journal: $($latest.FullName)"
        Get-Content $latest.FullName | Select-String -Pattern 'CtrlWiz|plugin|error|fail|PackageContents|ribbon' -CaseSensitive:$false
    } else {
        Write-Host "No .nwjsf journal files found"
    }
} else {
    Write-Host "Journal directory NOT CREATED at $journalDir"
    Write-Host "Checking broader NW2025 AppData dir:"
    $nwDir = Join-Path $localAppData 'Autodesk\Navisworks Manage 2025'
    if (Test-Path $nwDir) { Get-ChildItem $nwDir -Recurse | Select-Object FullName } else { Write-Host "NW2025 AppData dir does not exist" }
}
```

STEP F — Check Windows Event Log for CLR failures:
```powershell
Get-WinEvent -FilterHashtable @{LogName='Application'; Id=1026} -MaxEvents 30 -ErrorAction SilentlyContinue |
  Where-Object { $_.Message -like '*roamer*' -or $_.Message -like '*CtrlWiz*' -or $_.Message -like '*navisworks*' } |
  Select-Object TimeCreated, Message |
  Format-List
# If no results, record: "No EventID 1026 entries matching roamer/CtrlWiz in Application log"
```

STEP G — Capture Fusion log results:
```powershell
Write-Host "=== Fusion log files in C:\FusionLogs ==="
$fusionFiles = Get-ChildItem 'C:\FusionLogs' -Recurse -Filter '*.htm' -ErrorAction SilentlyContinue
Write-Host "Total .htm files: $($fusionFiles.Count)"
$fusionFiles | Select-Object FullName, LastWriteTime, Length | Format-Table -AutoSize

# Look for roamer-related entries specifically
$roamerLogs = $fusionFiles | Where-Object { $_.FullName -like '*roamer*' -or $_.FullName -like '*Navisworks*' -or $_.FullName -like '*CtrlWiz*' }
Write-Host "=== Roamer/NW/CtrlWiz specific logs ($($roamerLogs.Count) files) ==="
$roamerLogs | Select-Object FullName, LastWriteTime | Format-Table -AutoSize
```

STEP H — CRITICAL: Disable Fusion logging immediately after capture:
```powershell
reg delete "HKLM\SOFTWARE\Microsoft\.NETFramework" /v EnableLog /f
reg delete "HKLM\SOFTWARE\Microsoft\.NETFramework" /v ForceLog /f
reg delete "HKLM\SOFTWARE\Microsoft\.NETFramework" /v LogFailures /f
# Leave LogPath in place so Plan 02 can read the captured files
Write-Host "Fusion logging DISABLED. C:\FusionLogs files preserved for analysis."
```

STEP I — Verify logging is disabled:

```powershell
$enableLog = (reg query "HKLM\SOFTWARE\Microsoft\.NETFramework" /v EnableLog 2>&1)
if ($LASTEXITCODE -ne 0) { Write-Host "EnableLog key removed — logging disabled OK" } else { Write-Host "WARNING: EnableLog still present: $enableLog" }
```
